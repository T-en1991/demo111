我将为您创建一个独立的模拟器项目，包含 Web 界面，用于模拟声通设备与主程序进行交互。

### 模拟器功能
1.  **模拟声通设备 (TCP Server)**：监听 **9200** 端口，等待主程序连接。
2.  **可视化界面 (Web UI)**：
    *   **查看指令**：实时显示主程序发送过来的指令（如 `FORWARD`, `LIGHTON` 等）。
    *   **模拟反馈**：可以手动输入经纬度、深度、电量等数据，点击按钮向主程序发送 `STAT` 状态包，驱动主程序地图上的机器鱼移动。
3.  **技术栈**：Node.js + Express + Socket.io，轻量且易于运行。

### 实施计划
1.  在项目根目录下创建 `simulator` 文件夹（作为独立项目）。
2.  创建 `package.json`，引入必要依赖。
3.  编写 `server.js`：同时启动 TCP 服务（模拟设备）和 Web 服务（提供界面）。
4.  编写 `public/index.html`：提供简单的操作面板。
5.  完成后，您只需进入该目录运行 `npm install` 和 `node server.js` 即可启动模拟器。
