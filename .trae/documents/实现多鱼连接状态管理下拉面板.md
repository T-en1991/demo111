这是一个非常好的 UX 改进建议，特别是考虑到我们刚刚实现了多鱼并发监控。使用一个“连接管理器”下拉列表来展示所有鱼的连接状态，比单纯在顶部显示当前鱼的状态要直观得多，也更符合“监控中心”的定位。

### 设计方案
我们将把现有的单一状态标签替换（或增强）为一个**带下拉列表的交互组件**。

#### UI 交互设计
1.  **触发器 (Trigger)**：
    *   保留现有的状态 Tag，或者简化为一个“连接图标 + 概览文字（例如：`2/5 在线`）”。
    *   点击该区域，弹出一个下拉面板（Popover / Dropdown）。

2.  **下拉面板内容**：
    *   **标题**：`机器鱼连接状态`
    *   **列表**：列出所有已配置的机器鱼。
    *   **每行内容**：
        *   鱼的名称（Name）
        *   状态指示灯（绿色=Connected, 灰色=Disconnected, 红色=Error, 黄色=Connecting）
        *   状态文本（已连接 / 未连接）
        *   **操作按钮**：提供快速 `连接` / `断开` 的小按钮，方便直接管理。

#### 技术实现
1.  **组件选择**：使用 Element Plus 的 `ElPopover` 或 `ElDropdown`。
2.  **数据源**：
    *   从 `fishControlStore` 获取 `fishMap`（所有鱼列表）和 `connectionStates`（所有连接状态）。
    *   计算属性：统计在线数量。
3.  **操作**：调用 `fishControlStore.connect(id)` 和 `disconnect(id)`。

2.  **增加操作功能**：在列表中添加连接/断开按钮。
